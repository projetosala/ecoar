# 2d-Game (Projeto do Professor Geraldo)

## Descrição
Um personagem turista chega a região de Alagoas e se depara com alguns problemas ambientais. E decide enfrentá-los passando por desafios, pelos biomas alagoanos a fim de resgatar os animais e os devolver a seu habitát, enfrentando chefões (problemas ambientais)
